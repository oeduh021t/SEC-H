# SEC-H (System for Engineering and Clinical Management)

Sistema especializado para gestão de ativos hospitalares e controle de ordens de serviço (OS) de engenharia clínica.

## 🚀 Funcionalidades
- **Gestão de Inventário:** Cadastro e controle de equipamentos médicos por setor.
- **Fluxo de Chamados:** Abertura, atendimento técnico e finalização de OS.
- **Histórico Clínico:** Registro cronológico de todas as intervenções nos equipamentos.
- **Notificações:** Integração com Telegram Bot para alertas de novas solicitações.
- **Infraestrutura:** Totalmente containerizado com Docker.

## 🛠️ Stack Tecnológica
- **Frontend:** React.js (Vite) + Tailwind CSS
- **Backend:** Node.js + Express
- **Banco de Dados:** MariaDB
- **DevOps:** Docker & Docker Compose
